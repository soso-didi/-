## 提交约定

为了方便回溯，每次代码更新后都会先提交再同步到 GitHub。

提交信息统一使用这个格式：

```text
<类型>: <一句话说明> (<YYYY-MM-DD>)
```

类型说明：

- `feat`：新增功能
- `fix`：修复问题
- `refactor`：重构但不改功能
- `docs`：文档改动
- `chore`：杂项、构建、配置、清理

示例：

- `feat: 添加导出按钮 (2026-08-18)`
- `fix: 修复文件保存失败 (2026-08-18)`
- `docs: 补充回溯说明 (2026-08-18)`
